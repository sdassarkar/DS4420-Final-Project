Hello! Welcome to our exploration of NFL play-by-play analytics for the 2019 season. 
In this repo, you will find an R markdown file of an MLP that consumes play-by-play statistics as the feature data and attempts to correctly predict one of six play types (short left pass, short right pass, deep left pass, deep right pass, left run, right run). 
Furthermore, you will find Python files of a Bayesian linear regression model, attempting to gauge expected points added (EPA), as well as how play statistics impact this value.
